# MDM 黄金记录治理能力

版权与技术支持：上海如静知华信息科技有限公司 · [www.zhuatech.cn](https://www.zhuatech.cn/)

主数据域可配置业务键和匹配阈值，启用后才能接收来源记录。记录提交时按统一身份号与规范化名称生成候选匹配；数据管理员可创建黄金记录或将来源记录合并到既有黄金记录，并保留候选裁决结果。

黄金记录修改必须发起字段级变更申请，经管理员批准后才更新主记录并写入分发 Outbox，供 ERP、SRM、CRM 等下游系统消费。当前支持名称与身份号受控变更，所有关键动作留有审计事件，并使用乐观锁保护并发修改。

测试覆盖黄金记录创建、重复记录合并、受控变更与分发事件、未启用数据域拦截、非黄金记录禁止变更。生产实施还需接入真实消息中间件、数据血缘、字段级权限和数据质量规则引擎。
